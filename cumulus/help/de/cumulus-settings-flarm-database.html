Einstellungen - Flarm Datenbank

Die Download Knöpfe sind nur verfügbar, wenn Cumulus nicht in Bewegung ist.

Cumulus kann Datenbankdaten von FlarmNet und OGN in der Flarmanzeige für Flarm Objekte mit verwenden, wenn es hier so konfiguriert wird. Um mehr darüber zu erfahren, schauen sie bitte auf die folgenden Webseiten:

  • FlarmNet
  • OGN

Die Flarm Datenbank Seite besteht aus den folgenden Elementen:

verwende Flarm Datenbank

Wenn die Checkbox aktiviert ist, werden Daten von FlarmNet und OGN, sofern sie zur Verfügung stehen, verwendet. Im anderen Fall nicht. Eine Verwendung setzt voraus, dass sie zuvor in Cumulus runtergeladen wurden.

Da sich die Datenmengen von FlarmNet und OGN überschneiden, geht Cumulus folgendermaßen damit um. Zuerst werden die FlarmNet Daten gelesen und anschließend die OGN Daten. Die OGN Daten überschreiben die FlarmNet Daten, bis auf die Funkfrequenz, wenn die Gerätekennung gleich ist. Bei OGN werden beim Einlesen nur die Geräteadressen vom Type 'F' (Flarm) und 'I' (ICAO) gelesen. Alle 'O' Einträge werden ignoriert.

Wurde für die Gerätekennung ein Flarm Alias in Cumulus definiert, wird dieser anstatt des Flugzeugkennzeichens verwendet.

Download FlarmNet URL

Dieser Eintrag verweist auf die aktuell benutzte URL, um FlarmNet Daten mittels Cumulus herunter zu laden. Falls die URL sich ändert, kann sie hier angepasst werden.

Beachte: Cumulus kann nur die FlarmNet Datei data.fln, die für XCSoar bereitgestellt wird, verarbeiten.

Download OGN URL

Dieser Eintrag verweist auf die aktuell benutzte URL, um OGN Daten mittels Cumulus herunter zu laden. Falls die URL sich ändert, kann sie hier angepasst werden.

Knopf Zähle

Wenn man den Knopf Zähle betätigt, kann man austesten, wie das definierte Filter sich auf die Anzahl der geladenen Flarm Datensätze auswirkt.

FlarmDB Filter

Wenn man nicht die kompletten FlarmNet und OGN Daten laden möchte, da diese sehr umfangreich sein können, kann man durch die Definition von Filterelementen diese einschränken. Ein Filterelement besteht aus einer Textkette und wird auf die Flugzeugkennzeichen angewendet. Es können mehre Filterelemente getrennt durch Leerzeichen oder Komma hier angegeben werden. Das Filterelement wird mit dem Kennzeichenbeginn verglichen und wenn es übereinstimmt, wird der Datensatz geladen. Beachte, dass der Filtervergleich Kontext sensitiv arbeitet. D.h. Kennzeichenbuchstaben sind in der Regel in den Datenbanken groß geschrieben.

Beispiel:

Wenn als Filterelement D definiert wird, werden alle Datensätze, deren Flugzeugkennzeichen mit D beginnt, geladen. Weitere Filterelemente können getrennt duch Leerzeichen bzw. Komma hinzugefügt werden.

Knopf Download

Wenn der Knopf Download betätigt wird, versucht Cumulus mittels der definierten URL die FlarmNet bzw. OGN Datei herunter zu laden. Voraussetzung ist, dass eine Internetverbindung existiert.

Knopf Standard

Drückt man den Knopf Standard werden die Konfigurationseinstellungen dieses Fensters auf Standardwerte zurügesetzt. D.h.

  • Die Checkbox verwende Flarm Datenbank wird deaktiviert.
  • Die URLs werden auf die in Cumulus hinterlegte URLs gesetzt.
  • Alle Filterelemente werden gelöscht.
