Settings - Flarm Database

The download button are only available, if Cumulus is not moving.

Cumulus may use database data in the Flarm display from FlarmNet and OGN for Flarm objects, if it is configured in that way. To get more information about that, please have a look at the webpages of:

  • FlarmNet
  • OGN

The Flarm Database configuration window consists of the following elements:

use Flarm Database

If the checkbox is activated, data from FlarmNet and OGN will be used, if they are installed in Cumulus, otherwise not.

Download FlarmNet URL

This entry shows the current used URL by Cumulus to download FlarmNet data. Here you can adapt the URL, if it has been changed.

Note: Cumulus can process only the FlarmNet file, which is provided for XCSoar.

Download OGN URL

This entry shows the current used URL by Cumulus to download OGN data. Here you can adapt the URL, if it has been changed.

Button Count

If you press the Count button, you can test, how many database records would be loaded by the defined filter.

FlarmDB Filter

If you don't want to load the whole FlarmNet and OGN data by Cumulus during run-time, you can define here, which subset of data should be loaded. A single filter item is a substring of the airplane registration. If the filter item matches the beginning of the registration sign during load, this database record is loaded, otherwise not. You can define several filter items divided by space or comma. Note, that the filter comparison works context sensitive.

Example:

If the filter item D is defined, all data records, which airplane registration starts with D will be loaded. Airplane registrations uses upper letters in the database.

Button Download

If you press the Download button, Cumulus tries to download the FlarmNet or OGN file by using the URL, defined to the right of the download button. Preconditions is, that an active Internet connection exists.

Button Default

If you press the Default button, all configuration items of the window will be set to their default values. That means:

  • The checkbox use FlarmNet Data is deactivated.
  • The URLs will be set to the value, stored internally in Cumulus.
  • All filter items are cleared.
